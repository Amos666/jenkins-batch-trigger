## VSCode 插件 UI 设计：Jenkins 批量触发 Pipeline

用户需求：设计一个 VSCode 插件，支持批量触发 pipeline、批量传参（界面可改）、实时状态展示（running/building/failed/success）、手动刷新按钮、多 pipeline 过滤批量选择、分组选择保存为过滤模板。纯 UI 交互设计，不写代码。

### 设计方案（三段式布局）
- **Activity Bar**：插件入口图标
- **Side Bar（原生 TreeView）**：pipeline 树视图，分组折叠 + checkbox 多选 + 分组全选胶囊 + 过滤模板区（保存/应用）+ 选择摘要条
- **Webview 主面板**：参数配置（统一参数绿色区 + 单项覆盖表格橙色高亮）+ 实时状态监控（四色统计卡 + 阶段进度条 checkout→build→test→deploy + 手动刷新按钮 + 自动刷新开关 + 失败重试）
- **Status Bar**：常驻汇总（X running · Y failed · Z queued）

### 关键交互优化
1. 双层参数模型：统一参数批量下发 + 单项覆盖差异化，橙色高亮覆盖项，覆盖时有警告提示
2. 刷新双模式：手动「立即刷新」+ 自动轮询开关，按需刷新省资源
3. 过滤模板双向连接选择步骤：一键应用历史选择 / 保存当前选择
4. 阶段进度条而非单一进度条，直接定位卡在哪个 stage
5. 失败项有「重试失败项」快捷操作，形成闭环

### 状态色规范
- success → 绿 #639922
- running → 橙 #BA7517
- failed → 红 #E24B4A
- idle/queued → 灰 #888780

## 真实 VSCode 插件实现（TypeScript + 真实 Jenkins）

用户决定：TypeScript + 直接接真实 Jenkins（凭据走 SecretStorage）。从线框转为可安装插件。

### 项目结构（Z:\workspace\jenkins-batch-trigger）
- `package.json`：manifest，activitybar 视图容器 `jenkins-batch-trigger` + tree view `…explorer`，命令（open/refresh/addGroup/trigger/abort/openBuild/openSettings/setApiToken），配置项 jenkinsBatchTrigger.{jenkinsUrl,username,trustSelfSignedCert,configFileName,autoRefreshInterval}。
- `tsconfig.json`、`.vscode/{launch.json,tasks.json}`（F5 extensionHost + compile task）、`.vscodeignore`、`README.md`、`media/icon.svg`。
- `src/types.ts`：Job(含 url/buildNumber/queue)、Group、Filter、ParamTemplate、Config、nextId。
- `src/configStore.ts`：读写工作区根 `.jenkins-batch-trigger` JSON；resolveWorkspaceFolder。
- `src/jenkinsClient.ts`：真实 Jenkins REST 客户端。Basic Auth(user:apiToken)→免 crumb；递归 tree 查询 `/api/json?tree=jobs[…](5层)` 拍平 buildable job；color→status（anime=running）；`/queue/api/json` 计队列；`buildWithParameters`/`build` 触发；`/<num>/stop` 中止；refreshJobs 用 hashId(fullName) 稳定 id。可选 self-signed cert。
- `src/webviewHtml.ts`：运行时把 `media/webview-script.js`（桥接脚本）拼进线框 HTML 的 CSS+body，注入 CSP(nonce)+nonce script。不重复维护 markup。
- `src/webviewProvider.ts`：WebviewPanel 生命周期 + postMessage RPC（load/syncFromJenkins/trigger/abort/refresh/openBuild/openSettings/saveConfig）。trigger/abort 后 refreshInPlace 更新状态（不落盘，瞬态）。saveConfig 写盘并刷新 tree。连接状态（jenkinsUrl）随 load 回传，webview 更新顶栏连接指示。
- `src/treeProvider.ts`：原生侧栏 tree，列出命名分组 + Open 入口。
- `src/extension.ts`：activate 注册命令/tree/SecretStorage token 命令。
- `media/webview-script.js`：线框脚本移植版，I/O 全走 acquireVsCodeApi + rpc（load/syncFromJenkins/trigger/abort/refresh）与 fire（saveConfig/openBuild/openSettings）。保留全部 UI 逻辑（分组/全选/参数JSON权威/触发预览/批量中止/队列列/构建link/模板）。
